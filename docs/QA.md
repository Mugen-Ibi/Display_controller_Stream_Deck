# 検証項目

| 要件・操作 | 検証方法 | 表示の確認 |
| --- | --- | --- |
| ボタンによる増減・プリセット | ダイヤルなし機種を模したSDKホスト・GCQ271HA実機 | ボタンタイトルの操作内容と実際の輝度 |
| 連打・複数ボタン・ダイヤル併用 | SDKホストで30回連打と混在操作 | 最新値へ収束、全アクション同期 |
| ボタン用設定 | Chromiumで3モード切替・再読込 | 変更幅とプリセットの切替、ダイヤル専用項目非表示 |
| 輝度取得と範囲変換 | Rust単体テスト・GCQ271HA実機 | 実機の値に対応する% |
| 通常回転 | SDKのWebSocketイベントから実機へ | 数値とindicator更新 |
| 高速回転・同一モニターの複数ダイヤル | 遅延バックエンドの単体テスト | 最新値へ収束 |
| 押下・押しながら回転 | SDKイベント統合テスト | 回転後にプリセットが発動しない |
| プリセット・タップ | SDKイベント統合テスト | 設定値・実機再取得 |
| 他アプリとの同期 | 外部値変更を模した単体テスト | ポーリング後の値 |
| モニター選択・再検出 | Chromiumで操作 | 選択値、検出中、接続済み |
| 通常刻み・押し回し刻み・プリセット設定 | Chromiumで入力 | 保持、上限下限、不正入力 |
| 未接続・DDC非対応・読み書き失敗 | 単体テスト・統合テスト・Chromium | 取得不可、未接続、エラー |
| ヘルパー停止・タイムアウト・不正応答 | 子プロセスの障害テスト | 失敗を返し、次回再起動 |
| 設定画面レイアウト | 360px/300px幅でスクリーンショット | 横はみ出しなし、主要操作が読める |
| 配布 | Elgato CLI validate/pack | パッケージ生成 |

実機の物理ダイヤルを手で回す検証と、長時間のスリープ・抜き差し・Monitorianとの同時操作は別途手動確認が必要。
`npm run verify:hardware -- GCQ271HA` は専用テストホストから実際のプラグインを起動し、輝度を少し変更して最後に復元する。現在値を復元するため、実行中は他の輝度操作をしない。
