Stream Deckのボタンでディスプレイの輝度を調整できるようになりました。ダイヤルのない機種でも使用できます。

### ダウンロード・インストール

1. このページの **Assets** から **com.ibimu.display-controller.streamDeckPlugin** をダウンロードします（Source codeのZIPは不要です）。
2. ダウンロードしたファイルをダブルクリックし、Stream Deckにインストールします。
3. **Display Controller → ディスプレイ輝度** をボタンへ配置し、対象の画面と操作を選びます。

### 追加機能

- ボタン操作：明るくする／暗くする／プリセットに変更。
- ボタンに操作内容と現在の輝度を表示。
- ボタンに適した設定画面。変更幅・プリセットを変更可能。
- 複数ボタン・ダイヤル間で輝度を共有し、連打時の通信を集約。
- v0.1のダイヤル操作・設定は継続して利用可能。

### 動作環境・検証

- Windows x64、Stream Deckアプリ6.6以降、DDC/CI対応の外部ディスプレイ。
- Node.js・Rustの別途インストールは不要です。Monitorianの常駐も不要です。
- 自動テスト24件、型検査、Clippy、Elgatoパッケージ検証。
- SDKイベント経由のGCQ271HA実機制御を検証。物理ボタン・ダイヤルを手で操作する検証は未実施です。
